Amis · refonte

Plus d’onglets. Une page, trois blocs : recevoir, ce que vous avez envoyé, vos amis.

Les doublons, et ce qu’ils deviennent

RecevoirUn seul tiroir, identique ici et sur la page Fragments. Le code dit ce qu’il contient ; l’écran de résultat montre une carte ou des fragments.
DonsDevient Codes envoyés : cartes et fragments dans la même liste, sans date, effacés après 24 h. La page Fragments n’en montre que les fragments.
ContactsDevient Vos amis, directement sur la page.

Ce qui change

  • Les onglets Contacts · Recevoir · Dons disparaissent : tout tient sur une page qui défile.
  • Touchez un ami pour le renommer ou le retirer. Donner une carte se fait depuis la Collection, envoyer des fragments depuis la page Fragments.
  • Ajouter un ami : votre code d’abord (à copier), puis son nom et son code collé, comme aujourd’hui.
  • Premier lancement : un état vide avec un seul bouton, Ajouter un ami (sans ami, aucun code ne peut être reçu).

Selon l’écran

  • Téléphone : une colonne, 3 codes visibles puis « Tout voir ».
  • Tablette : amis en tuiles sur 2 colonnes.
  • Paysage et ordinateur : amis à gauche (2 colonnes, 3 sur grand écran), codes envoyés à droite.

Dans la démo

  • « Coller le code » reçoit une carte, « Importer un fichier » reçoit des fragments, pour voir les deux résultats.

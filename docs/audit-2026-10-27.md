## Lot 4 — Nettoyage du code

- Anciens carnets et composant Symbol retirés ; exports privés et constantes inutilisées nettoyés ; dépendances de build reclassées et plugin SSL retiré. Normalisation et durées partagées ; hook temporaire et bouton de confirmation commun, attributs et tailles préservés.
- `npm run check` : 113 tests réussis. `npx knip` : aucun signalement ; seule la référence JSX explicitement conservée est exclue de l’analyse. Trois types privés supplémentaires détectés par Knip ont perdu leur export.
- Knip récent : liaison native refusée par Windows ; exécution réussie avec son repli WebAssembly officiel installé uniquement dans le cache npm (aucune dépendance ajoutée au projet). L’ancienne version essayée était incompatible avec TypeScript 6.
- Test e2e d’échanges actualisé : parcours ami/copie/collage actuel, transfert chiffré et antirejeu ; presse-papiers isolé dans le test pour les trois navigateurs. Les tests existants utilisaient des contrôles retirés de l’interface. Validation complète des trois moteurs prévue après les dernières modifications pour éviter les rechargements HMR.

## Lot 5 — Styles

- Chaque classe listée recherchée dans le code applicatif : aucune référence. Retrait sélectif des branches mortes, conservation des dispositions Fusion/Gundam et de `--accent`. Aucun sélecteur exact répété dans un même contexte ne subsiste ; ordre relatif des blocs média conservé. Les déclarations média déjà annulées par des règles tardives ont été retirées avant regroupement pour garder la cascade.
- `npm run check` réussi (113 tests). Le garde-fou CSS compare désormais toutes les déclarations finales des sélecteurs actifs à la démo ; une égalité textuelle intégrale ne serait plus adaptée au nettoyage demandé.
- 60 captures finales : géométrie identique au lot 0 et styles calculés identiques au lot 4. 59 images strictement identiques pixel par pixel au lot 4 ; sur la dernière, 30 pixels du bord de la vignette Envois varient de 5 niveaux au maximum, sans changement de style ou de taille (rasterisation).
- Safari : le masque Full Art reste `-webkit-mask-image:none`. L’ancien gradient, déjà annulé, a été supprimé. Une éventuelle réactivation du masque reste une décision séparée du propriétaire.
- Autre anomalie : le compilateur élimine `backdrop-filter:none` à côté de son équivalent préfixé mais laisse le flou standard d’une règle antérieure. Pour conserver le rendu publié (flou standard 9 px et reset préfixé), la règle standard vit dans un contexte `@supports`, avant le reset. Cela évite une différence visible des fonds de modales sans réintroduire de doublon dans un même contexte.
- Tests de filtres : Échap est maintenant envoyé depuis une option focalisée, nécessaire sur WebKit où le clic seul ne focalise pas les boutons. L’attente du premier rendu différé précède le comptage des cartes. Les scénarios restent limités à 45 s ; le parcours complet à deux joueurs dispose de 90 s pour ses navigations et opérations cryptographiques (46 s observées sur WebKit).

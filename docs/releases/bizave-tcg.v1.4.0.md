# bizave-tcg.v1.4.0

Version du 2 novembre 2026, notification de mise à jour 5.

- Piles et aperçu réunis dans un carrousel plein écran, avec navigation tactile, favoris, don et recyclage.
- Partage PNG Story ou carte transparente, couleurs suivant le thème et halos de rareté. Le premier export attend le décodage complet des illustrations.
- Options organisées en rubriques dépliantes, personnalisation du format partagé et des actions de l’aperçu. Navigation plus opaque et moins floutée.
- Chargement par skeleton animé neutre ; aucun retour au placeholder pour les illustrations déjà chargées pendant la consultation.
- Titres des cartes classiques corrigés, fragments et légendes alignés, réserve achetée intégrée au compteur des boosters.
- Eli veilleuse de nuit et Nana Office Lady ajoutées à Memory Frame : 161 modèles, catalogue de 304 modèles illustrés.
- Note du propriétaire conservée avec une ligne vide avant le code DEE5-AVCY-8L4W-JL7A, donnant un paquet Memory Frame utilisable une fois par sauvegarde.

Publication statique Firebase Hosting sur `bizave-tcg`, dépôt GitHub sur `main`. Les données locales et le schéma de base restent compatibles. Les fichiers privés et les originaux restent hors publication.

Contrôles détaillés dans [VALIDATION.md](../../VALIDATION.md) et [docs/apercu-partage.md](../apercu-partage.md).

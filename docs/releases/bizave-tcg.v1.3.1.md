# bizave-tcg.v1.3.1

Version du 31 octobre 2026, publiée sur Firebase Hosting avec les sources sur la branche GitHub `main`.

- Nouvelle illustration pour Soirée film #3 ; descriptions des stands Bizarre Aventure sans scores.
- Suppression de la parallaxe interne et du surplus de cadrage sur toutes les cartes, avec maintien de l’inclinaison 3D et des reflets.
- Full Art : titre compact au-dessus de la description, espace de 6 px, liserés de 2 px, pictogrammes à 16 px du haut. Encarts clairs à 65 %, flou de fond à 2 px ; les alternatives conservent leur traitement sombre et doré. Typographie harmonisée avec les Classiques.
- Options : contrôles compacts pour l’apparence, la collection et l’envoi ; sélecteur personnalisé utilisable au clavier. ID joueur, code cadeau, compte et développement conservés.
- Couverture des piles : dernière obtenue, plus rare ou moins rare, indépendamment du tri. Réglage enregistré dans les préférences locales.
- Favoris : enregistrement immédiat, maintien de l’aperçu et des piles pendant l’interaction, actualisation du filtre à la fermeture. Retour à toute la collection sans réouverture spontanée.
- Dix nouveaux codes donnant chacun deux boosters Memory Frame et 100 fragments, crédités dans une seule transaction. Les listes privées restent locales ; seul le code annoncé dans la note de mise à jour est rendu public.
- Compteur de notification porté à 3 avec la note demandée et son cadeau.
- `/test`, sa configuration de développement et les listes privées restent hors Git et hors build publié.
